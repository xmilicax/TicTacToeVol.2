# TicTacToeVol.2

## About Application 

###### [ENG]
The app is based on the famous Tic Tac Toe multiplayer game. The twist in this one is that after 3 moves, the move is deleted. 
Rules are very simple:
    - Players take turns placing their marks in empty squares on the grid.
    - After each player has placed three marks, their oldest mark is automatically removed when they place a new one. 
    - The objective is to align three of your marks in a row — vertically, horizontally or diagonally. 

The first player to achieve this wins the game!

**Technologies used**: HTML, CSS (Tailwind CSS), JavaScript 

###### [SRB]
Aplikacija je kreirana po uzoru na popularnu Iks Oks igru za dva igrača. Specifičnost leži u tome što se potez, nakon 3 poteza, briše. 
Pravila su veoma jednostavna:
    - Igrači naizmenično postavljaju svoju oznaku u praznom prostoru na polju.
    - Nakon što je igrač postavio 3 oznake, pri postavljanju novog, najstariji se briše kada postave novi.
    - Cilj je da igrač postigne 3 iste oznake u redu - vertikalno, horizontalno ili dijagonalno.

Prvi igrač kojem ovo pođe za rukom osvaja partiju!

**Korićene tehnologije**: HTML, CSS (Tailwind CSS), JavaScript
